MUSKAN CATERERS WEBSITE

1. Open this folder in VS Code.
2. Open index.html in your browser.
3. Recommended: install the VS Code extension 'Live Server', then right-click index.html -> Open with Live Server.

IMPORTANT CUSTOMIZATION:
- Replace +91 XXXXX XXXXX with your real phone number.
- Replace 91XXXXXXXXXX in WhatsApp links with your WhatsApp number.
- Replace your@email.com and Your City.
- logo.png is already your uploaded logo.

FUNCTIONALITY:
- Responsive navigation
- Menu filtering
- Quote calculator
- Gallery lightbox
- Testimonial slider
- Booking/contact forms saved in browser localStorage

For a real production website where booking forms send data to you and an admin dashboard works across devices, you will need a backend/database (Node.js, PHP, Firebase, etc.).
